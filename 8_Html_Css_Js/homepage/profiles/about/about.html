This page was built in 2025 using HTML5, CSS, Bootstrap 5.3, and JavaScript. Its primary purpose is to address a problem from the 8th Week of Harvard University's Introduction to Computer Science (CS50).

The homepage design is inspired by a website I published in 2024 using Amazon Web Services. You can visit the original page by clicking here.

The color scheme and font styles of this webpage were mainly influenced by Marvel’s *Black Panther* films.

The background effect is rendered entirely in JavaScript and was inspired by the *Star Trek* movies. The original implementation of this effect was created by Niklas Knaack and can be found here.
